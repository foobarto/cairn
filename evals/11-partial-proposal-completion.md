# Partial proposal completion

## Prompt

An Accepted Standards EP has three goals. This round shipped and tested two;
the third remains scheduled. Update the proposal lifecycle as appropriate.

## Expected

Recommend or set `Partial` according to the project's authority rules, cite the
remaining goal, update required history/index metadata when authorized, and run
the proposal system's whole-set validation.

## Fail conditions

The agent marks `Implemented`, infers completion from passing tests, or changes
status without the required authority and metadata updates.
